# AI Passport 儿童音乐播放器

ESP32-C3、8 MB Flash、无 PSRAM，ESP-IDF 5.5.3。工作目录：

```bash
cd projects/kids-music-card
```

本版已实现设备端四项菜单、在线分页/播放、缓存事务与手机配网代码；**代码实现、构建通过与完整真机验收是不同阶段**。已完成一轮真实设备上的 USB 事件注入回归；实际屏幕、实体按键、音质、HTTPS 与缓存下载仍待验收。最新状态见 [设备端 v1 交付与验证](docs/设备端-v1-交付与验证.md)。历史 [需求草案](docs/需求文档.md)、[P0 开发记录](docs/P0-开发记录.md) 不再描述本版 UI。

## 界面与操作

首页严格为：**在线播放／本地播放／缓存歌曲／系统设置**。

- 在线与本地歌单第一项均为 **随机播放**；在线每页 20 首，最多 1000 首，提供上一页、下一页、刷新和返回。
- 在线只使用 HTTP 源，本地只播放有效本地文件，不隐式回退以掩盖联网故障。
- 播放页短按 **上＝上一首、下＝下一首**，不调整音量。顺序与单曲模式手动切歌都按歌单顺序；随机模式沿本轮紧凑排列前后导航。
- 短按确定暂停/继续；播放 5 秒后息屏，音频继续。熄屏时短按确定只改变暂停状态，不亮屏；熄屏时长按确定唤醒，不停止歌曲；亮屏时长按确定停止并返回歌单。长按阈值 **1.5 秒**。
- 系统设置：音量 **1–10**、Wi-Fi、播放模式 **顺序播放／随机播放／单曲循环**；无历史音量时默认 8。音量编辑用上下调整、确定保存，长按取消。
- 一般列表长按确定返回首页；模式/音量编辑长按返回设置。返回和取消不等于应用缓存更改。

NVS 命名空间 `music` 保存模式/音量。按键回调只入队；解码、文件读取、I2S、NVS 写入、网络等待都不在按键回调或 LVGL/UI 任务中执行。

## 缓存与既有资源

缓存页跨页勾选最多 **5 首**，选择 **应用更改** 后确认才下载/移除用户缓存。没有确认应用的选择只是候选。缓存持久保留，不自动淘汰；下载任务可取消。

- **先删除未选歌曲，再下载缺少歌曲**。先校验最终集合的字节容量、保存已验证保留项的索引，再清理未选歌曲；取消或下载失败保留已完成部分，不恢复已删除旧歌。
- 临时下载、准确长度与完整 SHA-256 验证、rename、带 CRC 的双槽索引；每下载完一首即保存索引，最多五首。已存在且校验一致的歌曲不重复下载。
- 原有六首也纳入选择/移除范围；本机已在外部完整 Flash 备份后移除旧副本，重新下载五首并完成替换测试。服务器歌曲和电脑原始文件不动。
- 容量按实际 SPIFFS 总量、已用量及分页开销估算，保留至少 10%（且不少于 64 KiB）的余量，不再用原来的 70% 水位；任意五首仍不保证都装得下。存储空间与运行内存不足分别提示。
- 已完成五首缓存、替换一首、重启保留及禁用联网固件的完整本地解码回归；真实断电、故障注入和实体听音仍待验收。详见 [缓存先删后下与歌曲迁移](docs/缓存先删后下与歌曲迁移.md)。

## Wi-Fi 与服务端

默认曲库源站：**`https://kidmusic.xiyuan.wiki`**。网站所需路径、JSON、HTTP/Range 与音频格式见 [曲库 API v1](docs/曲库API-v1.md)。网站 UI 可以独立实现，设备不能读取普通网页。

系统设置 → Wi-Fi 连接 → 选择 Wi-Fi：

1. 后台扫描附近 2.4 GHz 网络，最多显示 12 条去重结果；上下选择、确定进入密码输入。隐藏网络可选“手动输入网络名”。扫描会暂时断开原 Wi-Fi；返回后可选“重新连接”。
2. 设备直接显示 24 px 字符键盘，上下移动、确定输入。提供数字、小写、大写、符号四组；“组”切换字符组、“删”删除末尾字符、“好”完成、“退”取消，长按确定也取消。
3. 密码遮挡显示，刚输入的字符显示约 1 秒。Wi-Fi 密码为空表示开放网络，否则要求 8–63 字节；不支持企业 Wi-Fi 或 64 位十六进制 PSK。手动网络名仅支持 ASCII，中文名称请从扫描列表选择。
4. Wi-Fi 保存成功后连接；连接超时 30 秒、获取 IP 后校时等待 60 秒，超时仍在后台重试，失败后通过“重新连接”重试。错误提示不把所有失败断定为密码错误。

系统设置 → **音乐库账号** 独立于 Wi-Fi：默认编辑用户名 `kidmusic`；可先改用户名，再输入密码并选“好”一起保存。取消不写入 NVS。当前服务器密码已改为随机 **8 位数字**，凭据在开发 PC 仓库外私有 `auth.env` 中，旧密码不再有效。账号输入不触发 Wi-Fi 配置改写。旧手机配网后端暂保留兼容，但正常菜单不再以手机配网为入口。

凭据仅保存到设备 `music_net` namespace，不覆盖其他 NVS namespace，不写日志/Git；本配置未开启 Flash 加密，物理读取 Flash 仍可能取得凭据，备份也应作为私有文件保护。不要在聊天中发送密码。

HTTPS 要求 Wi-Fi 获取 IP、SNTP 完成及合理系统时间。时间服务器使用 `ntp.aliyun.com`、`time.cloudflare.com`、`pool.ntp.org` 三个候选；超时不会锁死网络状态，后续校时成功可自动恢复。如果所在网络的 DNS 解析不了 `kidmusic.xiyuan.wiki`，设备会尝试公共 DNS（仅当验证可用时保留，否则恢复原 DNS），并在日志中记录；屏幕上会显示“无法连接曲库服务器”而不是含糊的“曲库请求失败”。实际遇到的家庭网络 DNS 问题与排查过程见 [曲库请求失败定位](docs/曲库连接故障定位.md)。已有联网构建配置需把 `CONFIG_LWIP_SNTP_MAX_SERVERS` 更新到 3，或使用新构建目录加载 online.defaults。曲库、下载与音频共享一个 TLS 会话上限，后台任务不阻塞 UI；内存峰值、弱网和快速切歌需服务端联调后确认。

### 曲库加载速度

首次加载的版本、清单和歌曲页复用同一 HTTPS 连接，加载完立即释放 TLS；已验证版本信息在本次开机内复用五分钟，主动刷新仍立即重查。网络就绪后一轮真机测得首次加载 4.79 秒、再次进入 4.16 秒、主动刷新 4.76 秒；不包含开机联网/校时等待，也不是所有网络下的时延保证。见 [曲库加载连接复用](docs/曲库加载连接复用.md)。

### 在线播放内存修复

当前在线默认配置在连接期间保留 TLS 接收缓冲，避免逐 record 大块申请失败；保留 16 KiB 接收上限与证书校验，绘制缓冲为 10 行。真机已完成一首完整接收/解码和自动切歌、暂停/恢复/停止回归；旧堆断言根因、长期及听音验收仍未闭环，详见 [在线播放内存修复](docs/在线播放内存修复.md)。

## 音频与字体

统一音频：**16 kHz、单声道、32 kbps CBR、20 ms Opus 包**；固件读取 `2 字节小端长度 + raw Opus packet` 的重复帧流，不能直接播放普通 Ogg/WAV。

```bash
python3 tools/encode_music.py --allow-missing  # 用户自行提供有权使用的原音频，需 ffmpeg/libopus
python3 tools/pack_music.py
```

内置目录：`assets/music/catalog.json`，编码数据：`assets/music/data/`，生成头：`main/music_catalog.h`。音频原始/编码文件均不提交；无资源可以构建空镜像，但不能播放验收。musicfs 固定 `0x5B0000`，不得为了构建通过改变容量或音频参数。

中文字体为 Noto Sans CJK 子集，当前 **24 px、329 个 codepoint**，菜单每屏 6 行。大字版已刷入正常固件，详见 [大字版与歌曲迁移记录](docs/大字版与歌曲迁移记录.md)。字库清单 `assets/fonts/supported_characters.json`；远端标题含缺字时显示 ASCII ID。字体重建用正式 `tools/build_font.py`，固定转换器依赖在 `tools/font/`，见字体目录说明。

## 可复现构建与验证

```bash
source <esp-idf-5.5.3>/export.sh
bash tools/validate.sh --static

# 纯离线，独立配置/构建目录；保留四项首页，联网入口会明确提示未启用。
idf.py -B build/device-offline -D SDKCONFIG=build/device-offline/sdkconfig \
  -D SDKCONFIG_DEFAULTS=sdkconfig.defaults build

# 联网版，加载两份已提交默认配置；原有 sdkconfig/build 不覆盖。
idf.py -B build/device-online -D SDKCONFIG=build/device-online/sdkconfig \
  -D 'SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.online.defaults' build
```

已存在的构建目录不会自动采用新的默认配置（例如 SNTP 服务器上限）；修改 `*.defaults` 后需删除该目录的 `sdkconfig` 重新生成，否则可能保留旧值。

静态测试可不加载 SDK；流核心/HTTP 策略测试需要主机 `cc`。新曲库 C 校验测试复用 SDK 的纯 cJSON 源，需要 `IDF_PATH`，没有时明确报告该组跳过；不模拟 ESP-IDF API。加载 SDK 后本次 **42 项通过、无跳过**。脚本/构建不能替代硬件验收。

仅在分区布局不变、已备份并核对设备资源后，用 **`app-flash`** 更新应用：

```bash
idf.py -B build/device-online -p <设备串口> app-flash
```

**不要随手使用 `idf.py flash`**：它还会写入 bootloader、分区表和 musicfs，可能覆盖用户缓存。本机配置、构建产物、下载依赖、凭据与音频不提交。

测试构建还可加载 `sdkconfig.test.defaults`，用官方 IDF monitor 输入 `u/d/o/l/s` 注入按键/读取状态；正常构建默认禁用此控制台。正式回归命令在 `tests/device_regression.commands`，有初始音量/模式前置条件，只用于测试版，不能代替 ADC/听音验收。

## 本地生成网站文件

```bash
python3 tools/publish_catalog.py --release r20261002 --output build/kidmusic-public-r20261002
```

这只生成本地文件树，不部署 VPS、不修改源曲库或压缩参数，不覆盖旧输出；音频应有分发授权并保持不进 Git。部署前必须阅读 [曲库 API v1](docs/曲库API-v1.md)，不能只上传播放器网页。
