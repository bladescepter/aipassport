# 设备键盘与联网超时修正

2026-10-03，工作目录 `projects/kids-music-card/`。

## 修改

- 系统设置新增独立“音乐库账号”；Wi-Fi 页改为“选择 Wi-Fi”，不再要求手机热点输入。
- 后台扫描 2.4 GHz 网络，显示最多 12 个去重名称，也可手动输入 ASCII 网络名；扫描暂时断开原网络，返回后可点重新连接。
- 24 px 设备键盘，8 列、数字/小写/大写/符号四组，上下移动、确定输入。“组/删/好/退”为换组、删除、完成、取消。长按取消。密码默认遮挡，最后输入字符显示约 1 秒。
- Wi-Fi 和音乐库账号使用不同保存命令，仅修改各自 NVS 键；驱动扫描、连接、NVS 写入由后台网络任务执行，不在 UI 内操作。编辑框不加载/回显旧密码。
- Wi-Fi 连接最多等待 30 秒；获取 IP 后校时最多等待 45 秒。失败显示错误，需手动重新连接，不再无期限停留“连接中”。先前无限等待的直接代码原因是没有总连接期限、重试无限进行；用户网络为何没有连接成功尚未确定，不能据此断定密码错误。
- Caddy 曲库密码已改为随机 8 位数字，用户名保持 `kidmusic`，配置和旧凭据已备份，新凭据 HTTP 验证 200。新凭据只存服务器私有 auth.env 与开发 PC 仓库外私有 auth.env，不进日志/Git。旧密码失效。
