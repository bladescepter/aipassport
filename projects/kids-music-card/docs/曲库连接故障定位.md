# 曲库请求失败：定位过程与结论

2026-10-03，工作目录 `projects/kids-music-card/`。设备为 ESP32-C3 音乐卡，服务器为 `kidmusic.xiyuan.wiki`。

## 现象

设备已配好 Wi-Fi、完成校时并显示“联网就绪”，但进入“在线播放”时提示曲库请求失败。

## 已排除的原因（有证据）

- **服务器与 Caddy**：从 VPS 本地直连源站验证；曲库 current/manifest/page 返回 200，认证错误返回 401，音频完整下载字节比对一致，Range 返回 206 且 Content-Length/Content-Range 正确。公网解析（8.8.8.8、1.1.1.1、223.5.5.5）均为 `NOERROR`、A 记录指向源站、TTL 300，无 DNSSEC 问题。
- **设备凭据**：读取设备 NVS 后确认 `auth_user`/`auth_pass` 与服务器当前凭据一致，用该凭据请求公网接口返回 200。凭据值未打印。
- **应用层内存/代码**：连接失败时 heap 约 54 KB、最大连续块约 43 KB，报错为 `ESP_ERR_HTTP_CONNECT` 且 TLS 证书标志为 0，即尚未进入证书校验阶段。

## 直接原因

设备端 DNS 解析失败。设备日志（临时诊断版）显示：

```text
DIAG dns_server[0]=192.168.50.1
DIAG dns kidmusic.xiyuan.wiki rc=202 addr=- in 6436 ms   ← EAI_FAIL
DIAG dns ntp.aliyun.com       rc=0   addr=203.107.6.88 in 0 ms
```

- 设备的 DNS 服务器（家庭路由器 `192.168.50.1`）**无法解析该域名**，但对其他域名（`ntp.aliyun.com`）正常，因此 Wi-Fi 与校时本身没有问题。
- 该网络**同时禁止**向公共 DNS（223.5.5.5、119.29.29.29，以及本机测试的 1.1.1.1/8.8.8.8）发查询，所以设备端自行改用公共 DNS 也无法解决。
- 开发 PC 所在网络（网关 `192.168.1.1`）可以正常解析该域名，说明域名与权威解析本身正常。

结论：这是**设备所在网络（192.168.50.x）的 DNS 解析问题**，不是固件缺陷、不是服务器故障，也不是凭据错误。可能原因包括路由器上游解析异常、DNS 缓存了旧的不存在记录，或路由器 DNS 过滤。

## 本次固件改进（已构建并刷入）

1. 进入在线列表时若网络尚未就绪，最多等待 20 秒（可取消），不再因为开机后校时未完成而立刻失败。
2. 元数据请求连接失败时最多重试 3 次；连接/握手超时从 1 秒提高到 5 秒（TLS 握手本身另有默认上限），整体仍受 25 秒期限约束。
3. 网络就绪后检查曲库域名解析：若网络 DNS 解析失败，先尝试公共 DNS（223.5.5.5、119.29.29.29），**只有验证能解析该域名才保留**，否则恢复原 DNS，避免连带破坏其他解析。
4. 错误提示区分原因：认证失败显示“音乐库用户名或密码错误”，连接/DNS 失败显示“无法连接曲库服务器”，不再统一显示含糊的“曲库请求失败”。
5. 修正 SNTP 服务器列表与 `CONFIG_LWIP_SNTP_MAX_SERVERS` 不一致会导致 `esp_netif_sntp_init` 返回 `ESP_ERR_INVALID_ARG`、网络层启动失败的问题：改为按编译上限运行时填充服务器列表。**旧构建目录的 `sdkconfig` 不会自动跟随默认配置更新**，本次已重新生成 `build/device-v1-release/sdkconfig`。

## 验证

- 42 项静态测试通过；联网版与离线版均构建成功（联网版 binary `0x1abec0`，应用分区剩余约 26%）。
- 刷入正常版（关闭测试控制台）后启动正常：Wi-Fi 获取 IP → 2.5 s，SNTP 同步 → 5.9 s，HTTPS 就绪 → 6.0 s；无 `ESP_ERR_INVALID_ARG`。
- 日志中明确记录当前网络解析失败与回退结果。
- 旧的 `tests/device_regression.commands` 页面编号已过时；本版设备导航回归使用 `tests/device_catalog.commands`（仅测试构建，不写凭据）。

## 仍需用户处理

在 192.168.50.x 网络侧任选其一：

1. 重启/刷新该路由器 DNS，或把路由器上游 DNS 改为可用服务器后重试。
2. 让音乐卡改连与开发 PC 相同的可用网络（网关 192.168.1.1）。
3. 用手机连该 Wi-Fi 打开 `https://kidmusic.xiyuan.wiki/v1/current.json`：若能出现密码提示或返回内容，说明手机侧解析正常，可据手机所用 DNS 设置调整路由器。

网络 DNS 修好后，再测试在线播放与缓存；设备旧六首仍未删除。

日志：`build/diag-probe.log`、`build/diag-dns-long.log`、`build/diag-dns-safe.log`、`build/catalog-release-build.log`、`build/catalog-release-flash.log`、`build/catalog-release-boot.log`。
