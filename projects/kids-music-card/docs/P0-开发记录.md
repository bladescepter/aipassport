原实现会把只有一个字节的帧头当作正常结束；现在显式报截断错误，不自动播放下一首。文件 I/O 错误也不再冒充 EOF。

分区表、音频参数、字体、歌曲文件和 `sdkconfig.defaults` 未改变。新增试验文案使用已覆盖的 ASCII；默认离线按键、NVS 音量/模式、息屏行为仍需固件回归确认。

## 2. 试验入口行为（源码设计，待实测）

- 开机不等待联网，先让菜单、按键及本地播放可用；缺少网络配置不擦除 NVS 或音乐分区。
- 默认构建不启用联网试验项。开启后，菜单在本地歌曲与模式项之间增加 `HTTPS (P0)`。
- 该项只读取一首固定、不可变 URL 的音频；不伪装成完整远程曲库，不进入本地随机集合。
- 测试音频播放结束后循环同一 URL，播放页标明 `P0 loop`，用于连续播放验收；本地歌曲的三种模式不变。
- 在线源不要求本地 SPIFFS 挂载成功。
- 暂停保留缓冲和半帧；网络任务在安全块边界暂停读取，最多保留一个额外的 512 字节待提交块。
- 停止/切歌只通知旧任务取消并释放源所有权，不在音频任务等待 TLS 调用结束；旧任务自行清理，不能向新源提交数据。
- 本适配器最多保留两个活动/退役源、一个 TLS 客户端；快速切换时旧任务尚未回收可能返回资源不足，必须在真机测试中评估体验。
- 网络失败不自动换成本地其他歌曲。Range 被忽略时不拼接 `200` 响应正文；显示 `Restart required`，用户长按返回后重新选择，受控从头开始。
- 其他失败当前显示简化的 `Error`；缓冲、连接、配网等正式 UI 留待后续完善。

## 3. HTTP 与线程约束

- URL 只由配置的 HTTPS 源站和单斜线开头的相对路径组成。P0 支持 DNS/IPv4 与可选端口；暂不支持 IPv6 字面量、百分号转义路径、查询或片段。
- 拒绝 URL 内嵌凭据、外域路径、反斜线、空路径段和 `.`/`..`；所有重定向都拒绝，包括同域重定向。
- HTTPS 必须具有 IP 连接、SNTP 同步和合理时间；使用证书 bundle，校验主机名和证书时间，失败不能跳过验证。
- 请求使用 Basic Auth over HTTPS，凭据无默认值，不通过 URL 传递。
- 请求 `Accept-Encoding: identity` 与 `Cache-Control: no-transform`；P0 要求 Content-Length，拒绝 chunked、压缩和关键头重复。
- `206` 的起始偏移、结束偏移、总长与响应体长度均须和预期相符。偏移只记录已提交到环形缓冲的字节；SDK 内部预取但未提交的字节重连后重新请求，已有缓冲和解码器半帧保留。
- `401/403/404/416` 及协议错误终止；408/429/5xx 和运输失败最多重试两次。限制为每个源生命周期两次，不因部分进度或暂停重置计数。
- 每次恢复窗口目标为 10 秒；HTTP I/O 超时候选为 1 秒。纯策略测试检查预算，但 DNS、TLS 建连、SDK 读头调用的真实阻塞时长尚未验证，不宣称已实现真机端到端的硬性 10 秒保证。
- 播放任务只读已缓冲数据；最多等待通知 20 ms 后返回处理命令。TLS、HTTP 读取及清理只由生产任务执行，不能跨任务同时操作同一 client。
- 缓冲核心自身无锁；HTTP 适配器在短临界区使用互斥锁，不能持锁执行网络 I/O。
- 完成任务保留源上下文直到拥有者关闭；已关闭源由生产任务在 I/O 退出后回收。不能提前重用旧缓冲或强制删除仍持有 client 的任务。
- 帧组装超时为 10 秒，包含累计短读时间；暂停时保留数据，恢复时重置组装等待起点。
- HTTP 策略限制单个头名/值的长度，但底层 ESP-IDF 解析器在调用头事件前仍可能分配额外内存；这不是对整个 HTTP 解析器的硬内存上限。须通过异常响应与低内存实测补充验证。

## 4. ESP-IDF 配置与私有 profile

以下仅供连接设备的电脑后续配置，不在 VPS 安装或执行 SDK。本轮没有进行烧录。

在 `projects/kids-music-card/` 内，加载 ESP-IDF **5.5.3** 后运行 `idf.py menuconfig`，核对最终生效值：

```text
CONFIG_APP_NO_BLOBS=n
CONFIG_ESP_WIFI_ENABLED=y
CONFIG_ESP_HTTP_CLIENT_ENABLE_HTTPS=y
CONFIG_MBEDTLS_CERTIFICATE_BUNDLE=y
CONFIG_LOG_DYNAMIC_LEVEL_CONTROL=y
CONFIG_LOG_TAG_LEVEL_IMPL_NONE=n
CONFIG_LOG_MAXIMUM_LEVEL <= 3（INFO 或以下）
CONFIG_MUSIC_ONLINE_P0=y
```

`Children's music player` 下可选择 16/32 KiB 总缓冲和独立的起播阈值；默认 16 KiB、4100 字节，约一秒压缩音频。二者不是已验收参数，不能据此承诺起播时延或内存余量。

组件依赖无条件声明，只有联网源文件的选择依赖 Kconfig：ESP-IDF 在加载配置前展开 `REQUIRES` / `PRIV_REQUIRES`，不能用 CONFIG 宏条件化依赖清单。

设备 NVS 命名空间 `music_net` 的 bootstrap 键：

| 键 | 类型与约束 |
| --- | --- |
| `ssid` | string，1–32 字节 |
| `wifi_pass` | string，WPA2 口令 8–63 字节；空字符串表示开放 AP，不支持 64 字符原始 PSK |
| `origin` | string，HTTPS 源站，最多 192 字节，无路径/查询/内嵌凭据 |
| `audio_path` | string，不可变音频的相对路径，最多 192 字节 |
| `auth_user` | string，1–64 字节可打印 ASCII，不含冒号 |
| `auth_pass` | string，1–128 字节可打印 ASCII |
| `size_bytes` | u64，测试裸 Opus 文件的准确字节数，非零 |

当前只有读取接口，**还没有正式 profile 写入工具或手机配网服务**。私有配置注入方式须在真实设备测试准备时落实；不能为了测试把凭据写进源码、日志或提交文件，也不能未经备份直接刷写整个 NVS 分区。

ESP-IDF `HTTP_CLIENT` 的 DEBUG 日志会打印 Authorization 和请求头。因此试验开关要求编译日志上限不超过 INFO，并在初始化时将该 tag 的运行级别降为 WARN。不能用真实凭据开启 HTTP_CLIENT 调试日志。

网络任务在启动、响应校验和退出时记录内部空闲堆、开机以来最低堆、最大连续块和任务栈水位；这些是待采集的观测点，最低堆并非 TLS 独立峰值。音频任务栈、欠载和播放质量仍需另外测量。

## 5. 验证结果与边界

从仓库根目录进入项目：

```bash
cd projects/kids-music-card
bash tools/validate.sh --static
```

累计 **32 项通过**：原有 3 项资源测试、15 项流式核心测试、14 项 HTTP 策略测试。通过主机 `cc` / `gcc` 以 C11、`-Wall -Wextra -Werror -pedantic` 编译生产核心模块；验证入口未修改，由 unittest 自动发现新增测试。无编译器时 C 测试显式跳过，不能视为已经通过。

覆盖包括：单字节短读、大小端与长度边界、各位置 EOF、半帧保存、超时、取消、长暂停恢复、有界缓冲与 10,000 次模型对照、真实文件读取、URL/路径安全、头部重复/溢出/注入、压缩/chunked 拒绝、206/200/416、鉴权/重定向/服务器错误、恢复计数与时间预算、保留已解码半帧的字节偏移恢复。

**主机测试不编译或运行 `music_http_source.c`、`music_network.c`、NVS profile、完整 music_app 或 ESP-IDF API。** SDK API 使用参考了 ESP-IDF 5.5.3 的公开头文件/实现及构建说明，不等同于构建通过。

未执行：ESP-IDF 固件构建、联网固件大小检查、设备烧录、服务器请求、TLS 实测、任务同步/回收压力测试、按钮和息屏回归、音频试听、断网恢复、堆/栈采样、30 分钟连续播放。VPS 未安装 SDK、未部署服务、未修改 Caddy。
