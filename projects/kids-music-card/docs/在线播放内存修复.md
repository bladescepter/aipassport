# 在线播放内存修复与验收边界

工作目录：`projects/kids-music-card/`。硬件：ESP32-C3，无 PSRAM；SDK：ESP-IDF 5.5.3。

## 故障与修复

旧诊断日志 `build/play-session.log` 明确记录 TLS Dynamic Impl 分别申请 12155、16749、14513 字节失败。紧随失败的最大连续空闲块为 11264、13312、10752 字节，总空闲量仍有约 25–28 KB。

SDK `port/dynamic/esp_mbedtls_dynamic_impl.c` 按 TLS record 长度动态申请接收缓冲，并在处理后释放。它不依赖 `SSL_VARIABLE_BUFFER_LENGTH` 开关。反复大块申请在本项目并发内存负载下失败，随后 HTTP 重试耗尽，播放器显示错误。

本次修改：

- `sdkconfig.online.defaults` 关闭 `MBEDTLS_DYNAMIC_BUFFER`，在连接生命周期保留 record 缓冲；显式保留 16384 字节输入上限、2048 字节输出上限及证书校验。
- LVGL 单 DMA 绘制缓冲改为 10 行（4800 字节），相较之前 40 行释放 14400 字节；分辨率、字体大小、颜色深度不变，代价是更多刷新事务。
- 保留本轮早先的解码器预分配、4 KiB 音频 ring、Wi-Fi 4/6/4 缓冲上限与连接/读取超时分离。
- HTTP 完整收取与播放器解码到 EOF 分别输出验收日志，避免把 `playing=1` 当作成功。
- 测试固件在 HTTP 开始、头检查、读取失败、结束等资源日志点检查堆完整性；正常固件不执行该检查。
- 修复主机曲库测试漏链接 `music_policy.c` 的问题。

不缩小 TLS 输入上限来迎合本地内存；512 字节应用读取或低音频码率不能限制对端 TLS record 大小。不修改服务器、音频、分区或设备 NVS/musicfs。

## 真机结果

最终参数的测试日志：`build/tls-fixed-stream3.log`。

- 曲库成功加载；真实选择第一首《歌唱祖国》。
- HTTPS 完整接收 857146 字节，播放器随后报告 `Playback completed: song=16`；头检查到完成约 216 秒。
- 自动切换下一首、暂停、恢复、黑屏长按唤醒、再次长按停止返回歌单均满足脚本断言。
- 本轮没有 TLS 分配/读取错误、重启、堆检查失败。最低内部空闲量 11132 字节。
- 之前 20 行绘制缓冲的固定 TLS 版本也完成同一首与控制回归，但余量更低，因此最终使用 10 行。
- 已加载 SDK 的主机/静态测试：42 项通过，无跳过；`git diff --check` 通过。
- 在线正常构建 `build/tls-release` 和离线构建 `build/device-v1-offline` 通过；修复了错误事件辅助函数误放在线条件编译内导致的离线编译失败。
- 正常固件已 app-flash，确认测试控制台关闭、动态 TLS 缓冲关闭、输入上限 16384；首次启动成功联网校时。最终仅移动公共错误函数后再次构建并 app-flash。

正式回归：`tests/device_stream.commands`。它依赖有效 NVS 网络/账号和初始六首曲库；不是任意曲库通用测试，也不是听音验收。

## 尚未闭环

早前 `block_locate_free` 断言的触发点未定位。普通 OOM 不足以解释分配器内部断言；本次正常测试不再复现，不能宣称已证明没有越界/堆损坏。

附加 `sdkconfig.heapcheck.defaults` 的轻量堆保护会增加内存开销：20 行绘制缓冲版本在 TLS setup 分配失败；10 行版本完整解码第一首，但中途/后续握手出现验签分配类错误，自动下一首回归失败。该诊断构建不用于交付，不能记录为堆保护回归通过；没有发现 canary 损坏也不能排除旧问题。

仍需实体听音、全部歌曲/多轮快速切换、弱网和缓存并发压力测试。正常配置通过一轮完整播放不是长期稳定性的证明。

## 可复现命令

```bash
source <esp-idf-5.5.3>/export.sh
bash tools/validate.sh --static
idf.py -B build/tls-fixed -D SDKCONFIG=build/tls-fixed/sdkconfig \
  -D 'SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.online.defaults;sdkconfig.test.defaults' build
idf.py -B build/tls-fixed -p <串口> app-flash
idf.py -B build/tls-fixed -p <串口> monitor <tests/device_stream.commands

# 正常固件不含 test/heapcheck defaults；新目录避免沿用旧配置。
idf.py -B build/tls-release -D SDKCONFIG=build/tls-release/sdkconfig \
  -D 'SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.online.defaults' build
idf.py -B build/tls-release -p <串口> app-flash
```

仅 app-flash，不覆盖歌曲/NVS。已有构建配置不会因 defaults 改变而自动更新，请使用新的构建目录保留旧配置。
