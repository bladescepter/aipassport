## 配置核对

SDK 5.5.3 的 `ESP_WIFI_ENABLED` 是隐藏 bool，在支持 Wi-Fi 的芯片上默认 `y`。因此，默认文件里的 `CONFIG_ESP_WIFI_ENABLED=n` 不会按普通可选开关生效，新生成的离线配置也显示 `y`，不是旧缓存污染。

离线构建实际保留 `APP_NO_BLOBS=y`，由 SDK CMake 排除无线二进制库；P0 未启用，不会调用网络初始化。后续应修正默认配置旁的说明，不能只看 `ESP_WIFI_ENABLED` 判断是否联网。

P0 实际生效配置：

```text
CONFIG_APP_NO_BLOBS=n
CONFIG_ESP_WIFI_ENABLED=y
CONFIG_ESP_HTTP_CLIENT_ENABLE_HTTPS=y
CONFIG_MBEDTLS_CERTIFICATE_BUNDLE=y
CONFIG_LOG_DYNAMIC_LEVEL_CONTROL=y
CONFIG_LOG_TAG_LEVEL_IMPL_CACHE_AND_LINKED_LIST=y
CONFIG_LOG_MAXIMUM_LEVEL=3
CONFIG_MUSIC_ONLINE_P0=y
CONFIG_MUSIC_ONLINE_BUFFER_BYTES=16384
CONFIG_MUSIC_ONLINE_START_BYTES=4100
```

本机验证数据保存在项目内被忽略的 `build/validation-63642d1/`：

- `offline/`、`p0/`：独立固件、ELF、map、分区表和音乐镜像。
- `sdkconfig.offline`、`sdkconfig.p0`：实际生成配置。
- `p0.defaults`：不含凭据的联网配置覆盖文件。
- `offline.log`、`p0-build.log`：成功构建日志。
- `offline-size.txt`、`p0-size.txt`：大小报告。
- `static.log`、`pack.log`：静态测试及资源打包结果。
- `p0.log`：首次失败记录，保留用于定位缺失 Wi-Fi 库的问题。

从项目目录加载 SDK 后，本机现有验证目录可按以下方式增量构建：

```bash
cd projects/kids-music-card
source <esp-idf-5.5.3>/export.sh
idf.py -B build/validation-63642d1/offline build size
idf.py -B build/validation-63642d1/p0 build size
```

首次构建采用 `idf.py -B <独立目录> -D SDKCONFIG=<独立配置绝对路径> -D SDKCONFIG_DEFAULTS=<默认配置列表> build`。离线只加载项目 `sdkconfig.defaults`；联网按顺序加载该默认文件及 P0 覆盖文件。首次生成配置时覆盖文件用 `CONFIG_LOG_DEFAULT_LEVEL_INFO=y`、`CONFIG_LOG_MAXIMUM_EQUALS_DEFAULT=y` 选择 INFO 日志上限，用 `CONFIG_MUSIC_ONLINE_BUFFER_16K=y` 选择缓冲容量。不要依赖机器上旧的 sdkconfig。

现有 `validate.sh --firmware` 没有独立构建目录参数。为保留旧缓存，本次分别调用其正式打包入口和 SDK 的标准独立目录构建命令，没有修改或包装验证脚本。

## 真机阶段仍缺什么

1. **设备连接与备份**：连接 USB 数据线，识别设备；读回现有完整 Flash 并校验，连同本地音源保存到仓库外。备份未完成前不刷机、不覆盖 NVS/musicfs。
2. **私有 profile 正式写入入口**：现有代码只有读取。建议添加仅测试配置启用的串口配置入口，由 SDK NVS API 仅更新 `music_net` 命名空间，不整体覆盖 NVS；禁止凭据回显或进入日志，完成后关闭入口。此为下一步实施建议，本次未实现。
3. **一首歌的 HTTPS 端点**：证书、Basic Auth、Content-Length、精确 Range/206、不可变音频路径与准确文件大小；不允许重定向、chunked 或内容压缩。尚未配置或验证服务器。
4. **运行时观测与回归**：补充音频栈/欠载观测，验证 TLS 最低堆、最大连续块、任务回收、暂停/停止响应、断网恢复、按键与息屏行为。
5. **P0 退出门槛**：16/32 KiB 参数比较及至少 30 分钟真实连续播放通过后，才进入 P1。固件构建成功不是硬件验收。

本文的应用分区已按最小范围刷入真机并确认启动，见 [P0 真机验证记录](P0-真机验证记录.md)。

注意：标准 `idf.py flash` 的生成参数包含 `musicfs` 写入。不要在没有备份和明确刷写范围的情况下直接执行构建输出中的 flash 命令。
